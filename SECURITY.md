# Politique de sécurité

## Versions prises en charge

Seule la **dernière version** reçoit des correctifs de sécurité. Les agents se mettent à jour automatiquement, sauf désactivation locale.

## Signaler une vulnérabilité

**N'ouvrez pas de ticket public.** Utilisez l'une de ces voies :

- GitHub : onglet **Security › Report a vulnerability** (signalement privé) ;
- courriel : **mb_berrou@protonmail.com**.

Indiquez la version, le système, les étapes de reproduction et l'impact estimé.

## Nos engagements

| Étape | Objectif |
|---|---|
| Accusé de réception | 72 heures |
| Première évaluation | 7 jours |
| Correctif critique | 7 jours |
| Correctif élevé | 30 jours |

Les délais de correction s'entendent après confirmation, selon la gravité (CVSS). Nous publions un avis de sécurité à la sortie du correctif, et créditons l'auteur s'il le souhaite.

## Périmètre

Dans le périmètre : l'agent, ses installateurs, la chaîne de publication (signature, workflow).
Hors périmètre : Coinbase, le système d'exploitation de l'utilisateur, les attaques exigeant un accès administrateur à la machine de l'utilisateur.
