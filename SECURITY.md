# Security policy

## Supported versions

Only the **latest version** receives security fixes. Agents update themselves automatically unless turned off locally.

## Reporting a vulnerability

**Do not open a public issue.** Use one of these channels:

- GitHub: **Security > Report a vulnerability** tab (private report);
- email: **mb_berrou@protonmail.com**.

Include the version, the operating system, steps to reproduce and the estimated impact.

## Our commitments

| Step | Target |
|---|---|
| Acknowledgement | 72 hours |
| First assessment | 7 days |
| Critical fix | 7 days |
| High-severity fix | 30 days |

Fix times start once the issue is confirmed and depend on severity (CVSS). We publish a security advisory with the fix and credit the reporter if they wish.

## Scope

In scope: the agent, its installers, the release chain (signing, workflow).
Out of scope: Coinbase, the user's operating system, attacks that require administrator access to the user's machine.
